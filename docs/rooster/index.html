Rooster ​

Rooster 将本地 Web 控制台、原生托盘、SQLite 执行记录和进程管理集中在一处。适合管理开发服务、后台进程、备份与同步脚本。

快速开始 ​

准备 Go 1.25+、Node.js 与 pnpm：

sh
git clone https://github.com/leancodebox/rooster.git
cd rooster
cd web
pnpm install
pnpm build
cd ..
go run ./cmd/roosterd

默认打开 http://127.0.0.1:9090。端口占用时会尝试后续 100 个端口，以启动日志中的 rooster ready 地址为准。原生托盘入口为 go run ./cmd/rooster，需要平台对应的 Fyne 图形开发依赖。

选择任务类型 ​

类型适用场景行为
常驻任务 resident开发服务、后台进程支持失败重启、始终重启或不重启，以及指数退避
定时任务 scheduled备份、同步、巡检五字段 Cron，可跳过重叠执行或允许并行

创建后先手动运行一次，检查执行历史与日志，再启用自动运行。停用定时任务仅停止未来调度，不会终止正在运行的命令；必要时单独停止执行。编辑或删除任务前，需停用任务并等待活动执行结束。

数据与运行环境 ​

  • ROOSTER_LISTEN：首选监听地址，默认 127.0.0.1:9090。
  • ROOSTER_DATA_DIR：数据目录，默认位于系统用户配置目录的 Rooster 下。
  • 数据库为 rooster.db，日志保存在 logs/；迁移或备份时需保留数据目录。
  • 支持工作目录、自定义 Shell、环境变量和执行日志。

Agent 接入 ​

接口用途
GET /api/health健康检查
GET /api/skillAgent 操作指导
GET /api/docs完整接口字段、响应和示例

控制台顶部的「Agent 接入」可复制当前实例地址和文档。API 接受执行请求不等于任务执行成功，需要继续检查执行历史。

服务默认仅监听回环地址，没有远程认证层；任务以 Rooster 进程的用户权限执行。请保持本地访问。
