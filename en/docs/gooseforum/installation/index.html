Installation ​

Use a release build ​

Download the archive for your platform from GitHub Releases:

bash
tar -zxvf GooseForum_Linux_x86_64.tar.gz
chmod +x ./GooseForum
./GooseForum serve

The server listens on port 5234 by default. The first registered user automatically becomes an administrator.

Build from source ​

You need Go 1.27+, Node.js 18+, and pnpm:

bash
git clone https://github.com/leancodebox/GooseForum.git
cd GooseForum
cd resource && pnpm install && pnpm build && cd ..
go build -ldflags="-w -s" .
./GooseForum serve
